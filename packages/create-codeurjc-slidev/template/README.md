# Slides

This is a [Slidev](https://sli.dev) presentation using the `codeurjc-slidev-theme` theme (draggable layout editor, code-highlight callouts, code-snippet import, and slide-title carry-over).

To start the slide show:

```bash
npm install
npm run dev
```

Edit `slides.md` and, when running the dev server, use the "Show editor" button to drag/resize the title, content, logo, and red bar, or drag code-highlight callouts to reposition them.

Reference code from the `code/` directory in a slide with:

```
<<< @/code/path/to/File.java java
```

See the [Slidev documentation](https://sli.dev) for general Slidev features.
